Create a full-stack SaaS web application named **KanoonPK** from scratch.

🟢 Hosting & Platform
• Entire app runs on Replit.
• Primary database lives inside a Docker container and is accessed securely via Docker API.

🟢 Data & Storage
• Database stores legal citations/judgments as mixed file types (.pdf, .jpeg, .txt, etc.).
• Implement OCR (Tesseract or OpenAI Vision) to extract searchable text from all files.
• Each record keeps BOTH the original file (for exact printing) and the extracted text (for fast search/display).
• When a user views a result:
   – Show clean text preview generated from OCR.
   – Provide a “Print Original” button that streams/prints the exact stored file.

🟢 User Features
1. Authentication & Subscription
   – Email/password sign-up/login, password reset.
   – Paid subscription (Stripe or similar). Only subscribers can access search features.

2. Search Modes
   – **Basic Search** → query ONLY the Docker database.
   – **Advanced/Citations Search** → database only, with filters (date range, jurisdiction, keywords).
   – **AI Advanced Search** → integrate OpenAI API; return results from BOTH AI engine and database, displayed in two clearly labeled sections.

3. File Handling
   – Allow bulk admin upload of PDFs/JPEG/TXT.
   – Auto-run OCR on upload, store extracted text and original file.
   – Original file must remain downloadable/printable.

🟢 Tech Stack
• Backend: Python (FastAPI) or Node.js/Express.
• Frontend: React (Next.js or Vite) with TailwindCSS.
• Database: PostgreSQL or MongoDB inside Docker container.
• OCR: Tesseract or OpenAI Vision.
• Security: JWT authentication, secure API keys.

🟢 Admin Panel
• Upload/manage legal files.
• Trigger re-OCR if needed.
• Monitor users and subscriptions.

Deliver a ready-to-run **Replit project**:
– Docker container with database schema + sample records.
– Backend API for search, OCR processing, and file streaming.
– Modern responsive frontend branded **KanoonPK** with search bar, result list, and print buttons.
– Clear documentation for deploying, updating the Docker database, and configuring OpenAI/Stripe keys.
