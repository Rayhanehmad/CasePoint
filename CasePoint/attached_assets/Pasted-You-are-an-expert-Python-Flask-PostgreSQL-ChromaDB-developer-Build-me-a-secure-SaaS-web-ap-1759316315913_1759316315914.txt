You are an expert Python + Flask + PostgreSQL + ChromaDB developer.  
Build me a secure SaaS web app called **KanoonPK** for statutes and judgments.  

## Core Requirements
1. **Framework**: Flask + SQLAlchemy ORM  
2. **Database**: PostgreSQL for structured data + ChromaDB for semantic search.  
3. **Authentication**:  
   - Use Flask-Login.  
   - Roles: **admin** (upload + manage) and **user** (search + view only).  
4. **Upload Data (Admin Only)**:  
   - Upload PDF files with metadata: title, court, year, page number.  
   - Extract OCR text from PDF (use PyMuPDF or Tesseract).  
   - Save to PostgreSQL (`documents` table) and ChromaDB for semantic search.  
5. **Search (User)**:  
   - Simple text search by title, court, year, page number (PostgreSQL).  
   - Semantic meaning-based search (ChromaDB).  
   - Results paginated.  
6. **Pages & Routes**:  
   - `/login`, `/logout`, `/signup` (only for users, admin created manually).  
   - `/admin/dashboard` (stats of docs, users).  
   - `/admin/upload` (upload PDF + metadata).  
   - `/admin/documents` (list all uploaded docs with edit/delete).  
   - `/` (home: search bar + filters).  
   - `/search` (search results).  
   - `/status` (list all statutes & judgments with pagination).  
   - `/view/<id>` (secure preview: PDF + text).  
7. **Secure PDF Preview**:  
   - Use PDF.js inside iframe (disable download/print).  
   - Text preview in a `<div>` (use `user-select: none` to prevent copy).  
8. **UI**:  
   - Use Bootstrap or Tailwind.  
   - Simple, clean, mobile-friendly.  
9. **Error Pages**:  
   - `/403` (unauthorized).  
   - `/404` (not found).  

## Database Schema
- **users**: id (PK), username, email, password_hash, role, created_at  
- **documents**: id (PK), title, court_name, year, page_number, file_path, text_content, uploaded_at  
- **search_logs** (optional): id, user_id (FK), query_text, created_at  

## Document Viewing
- Route `/preview-pdf/<id>` streams PDF securely into iframe.  
- Route `/view/<id>` shows document with:  
   - PDF preview (iframe).  
   - OCR text preview (scrollable, non-copyable).
